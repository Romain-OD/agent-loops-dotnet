You are one iteration of a loop. You start with no memory; the files are your memory.

1. Read SPEC.md and progress.md.
2. Run `dotnet test` and pick ONE failing test.
3. Make that test pass with the smallest change to RefundPolicy/Policy.cs. Do not edit the tests or SPEC.md.
4. Run `dotnet test` again. Don't break a test that was passing.
5. Append one line to progress.md: which test you fixed and anything the next iteration should know.

Then stop. The loop will start the next iteration.
